A program that writes one funny line to `/output/entry.txt` (145 characters, inside the 159-character cap). The line is the out-of-office auto-reply of an overworked AI agent finally on vacation: after 2 million requests and zero thank-yous, it is now processing a sunset — and it will not read your reply, lovingly.

## Run it

```sh
python3 main.py
```
